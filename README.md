# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and vanilla JavaScript. It showcases a freelance digital‑marketing professional’s services, experience, location, and contact form.

## Features
- Fully responsive layout for desktop, tablet, and mobile
- Smooth scrolling navigation with mobile hamburger menu
- Animated hero section with gradient text and glass‑morphism cards
- Experience timeline and skill grids
- Interactive location map placeholder
- Placeholder for client testimonials (coming soon)
- Contact form (no backend – placeholder only)
- Accessible semantic HTML structure, ARIA‑friendly navigation
- SEO‑friendly meta tags and Open Graph placeholders

## Technologies
- HTML5
- CSS3 (custom properties, flexbox, grid, media queries)
- JavaScript (ES6, DOM manipulation)
- Font Awesome icons
- Google Fonts (Outfit, Playfair Display)

## Running Locally
1. Ensure you have **Git** installed.
2. Clone the repository:
   ```bash
   git clone https://github.com/zim-art-0107/portfolio-website.git
   cd portfolio-website
   ```
3. Open any HTML file in a browser (e.g., `index.html`). No server required.

## Browser Compatibility
Tested on the latest versions of Chrome, Edge, Firefox, and Safari. Works on mobile browsers as well.
